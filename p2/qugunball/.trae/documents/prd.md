## 1. 产品概述

**热血曲棍球**——一款六人制冰上对抗游戏，延续热血系列夸张逗趣像素风。圆脑袋小短腿的角色穿着厚实冰球护具，在冰面上滑行、冲撞、抡杆、打架。规则只有一条：把球打进对方球门，不管用什么手段。
- 面向喜欢热血系列、派对对战游戏的玩家，支持本地双人同屏对抗
- 核心卖点：冰面惯性物理 + 打架系统 + 必杀技 + 道具大乱斗，营造混乱、热血、搞笑的冰上大乱斗体验

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 |
|------|------|
| 玩家1（红队） | 键盘WASD区控制，操控红队全部6名球员 |
| 玩家2（蓝队） | 键盘方向键区控制，操控蓝队全部6名球员 |

### 2.2 功能模块
1. **主菜单页面**：游戏标题、开始比赛、操作说明、队伍选择
2. **比赛页面**：冰球场、6v6对抗、道具、必杀技、计分板、计时器
3. **结果页面**：比分展示、MVP球员、精彩回放文字描述、重新比赛/返回菜单

## 3. 核心流程

比赛主流程：玩家从主菜单开始 → 选择比赛时长 → 进入比赛 → 开球 → 双方操控球员在冰面对抗 → 进球后重置开球 → 时间结束 → 显示结果 → 重新比赛或返回菜单。

比赛中的核心循环：控制球员移动（冰面惯性）→ 争抢冰球 → 使用道具/打架/必杀技 → 射门得分 → 庆祝/懊恼动画 → 重置开球。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：冰蓝白（#E0F4FF）为底色，热血红（#FF2D2D）和活力蓝（#2D7BFF）为两队主色
- **像素风**：所有角色、UI元素均采用8-bit/16-bit像素风格，圆脑袋小短腿角色设计
- **字体**：像素风格字体（如"Press Start 2P"），标题大字带描边阴影
- **按钮**：像素风3D凸起按钮，按压时有下沉效果
- **布局**：全屏Canvas游戏区域，HUD叠加在画面上方/下方
- **动效**：像素风粒子（冰屑、火花）、帧动画（角色动作）、屏幕震动（碰撞/进球）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主菜单 | 标题 | 像素风大字标题，冰球撞击动画背景，闪烁霓虹效果 |
| 主菜单 | 菜单项 | 像素风3D按钮，选中时放大抖动 |
| 主菜单 | 操作说明 | 像素风对话框，双人键位图示 |
| 比赛 | 冰球场 | 俯视角Canvas，白色冰面+红色中线+蓝色争球圈 |
| 比赛 | 球员 | 像素风角色（16x16~24x24），不同颜色区分队伍 |
| 比赛 | HUD | 顶部居中比分板，两侧队伍颜色标识，底部蓄力条 |
| 比赛 | 道具栏 | 屏幕两侧道具图标，拾取高亮 |
| 结果 | 比分 | 超大像素数字，胜方颜色闪烁 |
| 结果 | MVP | 像素风球员肖像+数据，星星环绕 |

### 4.3 响应式
- 桌面优先设计，游戏Canvas固定比例（16:9），居中显示
- 小屏幕自动缩放Canvas，保持可玩性
- 键盘为唯一输入方式，双人共用一个键盘

### 4.4 游戏场景设计
- **视角**：俯视角（Top-down），略微倾斜的2.5D效果
- **冰面**：白色带蓝色渐变，有微弱反光效果，滑行留下刀痕轨迹
- **挡板**：四周木色挡板，碰撞时有弹性反弹
- **球门**：标准冰球球门造型，球进时有网抖动效果
- **氛围**：观众席像素小人欢呼，进球时纸屑飞舞
